# Global SDG Progress Prediction

## Project Overview
This project analyzes United Nations Sustainable Development Goal (SDG) 1: No Poverty data using Python and Machine Learning.

The goal is to explore historical indicator trends and build a Linear Regression model to estimate future values.

## Objectives
- Explore and clean UN SDG data.
- Analyze poverty-related indicators over time.
- Visualize historical trends.
- Train and evaluate a Linear Regression model.
- Generate future indicator predictions.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab
- GitHub

## Methodology
1. Load and explore the dataset.
2. Select an indicator and prepare yearly observations.
3. Visualize historical data.
4. Split the data chronologically into training and testing sets.
5. Train a Linear Regression model.
6. Evaluate predictions using Mean Absolute Error (MAE).
7. Generate future estimates and save results as CSV files.

## Project Files
- `Goal1.xlsx` — original dataset, if included.
- `SDG_Prediction.ipynb` — analysis and ML notebook.
- `sdg_future_predictions.csv` — future estimates.
- `sdg_test_results.csv` — actual versus predicted test results.

## Important Note
Predictions are experimental estimates based on historical data and Linear Regression. They are not official United Nations forecasts.
